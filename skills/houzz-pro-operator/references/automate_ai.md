# Houzz Pro AutoMate AI Capabilities

This reference details how and when to utilize Houzz Pro's built-in AutoMate AI features to increase efficiency. 

*Note: Most AutoMate features are optimized for the desktop experience.*

## 1. Financial Documents (Estimates & Proposals)
**Use Case:** Rapidly generating line items and categories for new estimates.
**How it works:** 
- Type an in-depth project description into the AutoMate prompt box, or use voice commands.
- The AI generates document line items and categories based on the description.
- **Action:** Always review and customize the generated document against RSMeans data before finalizing.

## 2. Estimate to Schedule
**Use Case:** Creating a project timeline immediately after estimate approval.
**How it works:**
- Within an Estimate, trigger AutoMate to transform the document into a Schedule.
- The AI analyzes line items and categories to build a timeline with detailed items and phases.
- **Action:** Review the generated schedule, adjust durations to the higher-end for client expectations, and add necessary milestones and task dependencies.

## 3. Daily Logs and Notes
**Use Case:** Polishing field reports and identifying action items.
**How it works:**
- After inputting raw text into a Daily Log or Note, trigger AutoMate.
- The AI cleans up the text, improves clarity, formatting, and fixes spelling errors.
- **Crucial Feature:** The AI scans the text and proactively recommends relevant tasks (e.g., if the log says "Need adhesive for paver stone," the AI suggests a task to procure adhesive).
- **Action:** Add the suggested tasks to the project's Tasks & Punchlist.

## 4. Takeoffs
**Use Case:** Automating material measurements from floor plans.
**How it works:**
- Upload a 2D PDF plan to the Takeoffs tool.
- On eligible simplified floor plans, AutoMate automatically detects spaces to measure area and length, and detects icons to create accurate item counts.

## 5. 3D Floor Plans
**Use Case:** Creating visual aids for clients.
**How it works:**
- **Create New:** Upload a 2D plan; AutoMate scans it and builds an accurate 3D floor plan.
- **Custom Products:** Select a 2D product image from the library; AutoMate creates a 3D version to place within the floor plan.

## 6. Clipper Tool
**Use Case:** Sourcing materials from vendor websites (e.g., Home Depot, Ferguson).
**How it works:**
- When using the Houzz Pro Clipper browser extension, AutoMate extracts product information from the vendor's site and automatically maps it to the correct Clipper fields, including pulling up to 5 relevant images.

## 7. Messages for Leads
**Use Case:** Drafting initial responses to new inquiries.
**How it works:**
- Within the Messages tab for a lead, the AI assistant evaluates the lead's request and reviews Wade's historical replies.
- It generates a ready-to-send response matching Wade's typical communication style.
- **Action:** Always present the drafted response to Wade for approval before sending.
