# Houzz Pro Platform Map

This reference provides the navigation structure and direct URLs for key features within Wade Custom Carpentry's Houzz Pro account.

## Global Navigation
The top navigation bar is always accessible and divided into five main sections:
1.  **Search**: Global search across all projects, leads, and contacts.
2.  **Projects**: `https://pro.houzz.com/manage/projects`
3.  **Leads**: `https://pro.houzz.com/manage/leads`
4.  **Financials**: `https://pro.houzz.com/manage/py/online/setup`
5.  **Company**: `https://pro.houzz.com/settings/team-members`

## The "Create New" Menu
A powerful shortcut available throughout the platform, typically accessed via a "+" icon or "Create New" button. It allows rapid generation of:
- File Upload
- Contract
- Estimate
- Invoice
- Retainer
- Change Order
- Task
- 3D Floor Plan
- Takeoff
- Daily Log
- Time Entry
- Selections Board
- Mood Board
- Lead
- Project
