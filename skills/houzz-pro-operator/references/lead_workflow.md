# Houzz Pro Lead Management Workflow (CRM)

This reference outlines how to manage leads and operate the CRM features within Houzz Pro for Wade Custom Carpentry.

## Lead Pipeline Stages
Leads in Houzz Pro are organized into a specific pipeline. When managing a lead, always ensure its stage accurately reflects the current status:

1.  **New:** Fresh inquiries that have not yet received a response.
2.  **Followed Up:** An initial response has been sent, awaiting client reply.
3.  **Connected:** Two-way communication established; discussing project details.
4.  **Meeting Scheduled:** An initial consultation or site visit is booked.
5.  **Estimate Sent:** A proposal/estimate has been delivered to the client.
6.  **Won:** The client has accepted the estimate and the project is ready to begin (convert to Project).

*Note: Leads can also be moved to Inactive (Snoozed or Archived) if they are unqualified or go cold.*

## Core CRM Operations

### 1. Responding to Leads (Using AutoMate AI)
When a new lead arrives via Houzz (Direct Message or Project Match):
1.  Navigate to the specific lead.
2.  Use the **AutoMate AI assistant** within the Messages tab.
3.  The AI will analyze the lead's request and Wade's historical replies to generate a response in his typical communication style.
4.  **Crucial:** Present the AI-generated draft to Wade for approval before sending.

### 2. Manual Lead Entry
If Wade receives a lead via phone or personal email:
1.  Navigate to `https://pro.houzz.com/manage/leads`.
2.  Click "Add Leads" and select manual entry.
3.  Fill in all available details (Name, Address, Project Type, Estimated Revenue).
4.  Set the Source to "Manually created lead".

### 3. Gmail Integration
Wade utilizes the Houzz Pro CRM extension for Gmail.
-   When reviewing Wade's emails, identify potential leads.
-   Remind Wade that he can use the Gmail extension to push these directly into the Houzz Pro "Active Leads" pipeline without manual data entry.

### 4. Vacation / Away Mode
If Wade is going on vacation or will be unavailable:
1.  Navigate to `https://pro.houzz.com/settings/communication#automated-reply`.
2.  Set up an auto-reply for incoming leads to ensure prompt acknowledgment and manage expectations regarding response times.
